# PhotoScreen

轻量、离线的双平台截图工具。支持 macOS 15.2+ Apple Silicon 与 Windows 11 x64。截图只在内存中编辑并复制到系统剪贴板，软件不保存截图历史或文件。

## 使用

启动后从菜单栏或系统托盘进入截图或设置。默认快捷键：Windows `Ctrl+Alt+A`；Mac `Control+Command+A`。在设置中可更换快捷键，并选择是否登录时启动。

拖动框选，或点击识别出的窗口。选择工具后可移动/调整选区；矩形、椭圆、箭头、画笔、文字和马赛克可通过工具栏绘制。实心箭头的长度由拖动距离决定，工具栏的线宽数值可调整箭头粗细。选择工具可选中图形并拖动修改；箭头可拖动两端手柄，其他图形可使用右下角手柄，双击文字可重新编辑。屏幕较窄时，工具栏内的工具可横向滚动。文字输入中 Enter 换行，Windows 按 Ctrl+Enter、Mac 按 Command+Enter 结束文字编辑。完成按钮或 Enter 复制图片，Esc 取消。右键重新框选。

复制后的图片由系统剪贴板保留，直到被其他内容替换。系统同步、剪贴板管理器和接收粘贴的应用可能保留各自的副本。

Mac 首次截图需要在系统设置中允许屏幕录制；授权后如仍无法截图，退出并重新打开 PhotoScreen。

## 安装和卸载

从本仓库 Releases 下载对应平台文件及校验文件。Mac 打开 DMG，将 PhotoScreen 拖入“应用程序”；更新前先从菜单栏退出，删除应用前先在设置中关闭开机启动。Windows 运行 EXE 安装器，安装到当前用户目录，通过开始菜单启动或卸载；更新和卸载前先退出托盘程序。

首版没有商业签名：macOS 可能要求在“隐私与安全性”中允许打开；Windows SmartScreen 或 Smart App Control 可能提示或阻止未签名程序。

## GitHub Actions

所有构建和打包在 GitHub Actions 运行。提交到 `main`、提交 PR 或手动运行可获取保留 14 天的双平台 ZIP、EXE 和 DMG 试用包。推送 `vX.Y.Z` 标签，或手动运行工作流并填写 `release_tag`，两端构建 EXE/DMG 并创建草稿 Release。下载草稿中的同一批文件，在 Mac 和 Windows 实机验收后再发布草稿。

验收覆盖：截图权限、窗口识别、不同缩放与多显示器、标注与中文输入、剪贴板粘贴和覆盖、安装升级卸载、开机启动，以及连续截图后的资源占用。Actions 的自动测试不替代真实桌面验收。

每次构建还上传 `Regression-*` 证据包，包含自动测试结果和基于合成图像的视觉报告。测试覆盖 macOS 图像方向转换、缩放裁剪、箭头轮廓及编辑、文字输入和剪贴板失败重试；它们不证明真实屏幕捕获、系统权限或各应用间粘贴已经通过。

具体步骤和记录表见 [实机验收说明](docs/acceptance.md)。
