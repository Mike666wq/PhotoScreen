# PhotoScreen

轻量、离线的双平台截图工具。支持 macOS 15.2+ Apple Silicon 与 Windows 11 x64。截图只在内存中编辑并复制到系统剪贴板，软件不保存截图历史或文件。

## 使用

启动后从菜单栏或系统托盘进入截图或设置。默认快捷键：Windows `Ctrl+Alt+A`；Mac `Control+Command+A`。在设置中可更换快捷键，并选择是否登录时启动。

拖动框选，或点击识别出的窗口；支持跨屏选区。紧凑工具栏会跟随操作所在的实际显示器，在窄屏自动换行。切换工具自动展开适用参数，重复点击当前工具可收起；颜色板提供预设、最近颜色和可展开的色相、饱和度、明度滑块。

画完保持当前工具，连续绘制；新对象保持选中，可直接拖动滑块调整样式。每种工具独立记住颜色、粗细和文字参数，仅选中旧对象不会覆盖默认值。实心渐粗箭头保持原有形状；拖动距离决定长度，粗细滑块范围 1–20，文字字号 10–72，字重 100–900。一次拖动只产生一步撤销。

按 V 切回选择工具并保留对象选择，拖动对象主体移动，拖动控制点缩放；箭头拖动两端，文字拖动左右手柄调整排版宽度。Shift 绘制矩形/椭圆时约束为正方形/圆形，绘制或调整箭头时约束到 45° 方向。画布方向键移动对象或选区 1 逻辑单位，Shift 为 10；Retina 的 1 逻辑单位对应多个设备像素。选区移动只改变裁剪范围，不带动标注。

工具快捷键：V 选择、R 矩形、O 椭圆、A 箭头、P 画笔、T 文字、M 马赛克。文字输入和滑块方向键各自优先，不会切换工具。马赛克按绘制顺序处理原图与此前标注，之后添加的标注保持清晰；预览和复制共用同一合成图层。

双击已有文字进入草稿编辑。Enter 换行，Windows Ctrl+Enter、Mac Command+Enter 结束编辑；文字编辑中的撤销/重做只影响草稿，提交后整次修改可作为一步画布撤销。Esc 优先结束输入法候选、取消未完成拖动或收起颜色板；输入时按 Esc 保留文字并结束编辑、收起参数，再按 Esc 取消截图。全文保留在当前会话内，超出选区时会提示最终裁切。

完成按钮、画布 Enter 或 Ctrl/Command+C 复制图片。复制失败保留编辑界面，可点击内嵌的“重试复制”。右键重新框选，保留已完成标注与撤销历史；尚无选区时右键取消截图。取消、屏幕布局变化或会话结束后释放原图与标注。
复制后的图片由系统剪贴板保留，直到被其他内容替换。系统同步、剪贴板管理器和接收粘贴的应用可能保留各自的副本。右键重新框选时，已画的标注和撤销历史会保留。

Mac 首次截图需要在系统设置中允许屏幕录制；授权后如仍无法截图，退出并重新打开 PhotoScreen。

## 安装和卸载

从本仓库 Releases 下载对应平台文件及校验文件。Mac 打开 DMG，将 PhotoScreen 拖入“应用程序”；更新前先从菜单栏退出，删除应用前先在设置中关闭开机启动。Windows 运行 EXE 安装器，安装到当前用户目录，通过开始菜单启动或卸载；更新和卸载前先退出托盘程序。

首版没有商业签名：macOS 可能要求在“隐私与安全性”中允许打开；Windows SmartScreen 或 Smart App Control 可能提示或阻止未签名程序。

## GitHub Actions

所有构建和打包在 GitHub Actions 运行。提交到 `main`、提交 PR 或手动运行可获取保留 14 天的双平台 ZIP、EXE 和 DMG 试用包。推送 `vX.Y.Z` 标签，或手动运行工作流并填写 `release_tag`，两端构建 EXE/DMG 并**直接发布** Release。发布后仍需在 Mac 和 Windows 实机按下面的验收清单自测；未通过的部分按「未验证」记录，修复后发新版本。

验收覆盖：截图权限、窗口识别、不同缩放与多显示器、标注与中文输入、剪贴板粘贴和覆盖、安装升级卸载、开机启动，以及连续截图后的资源占用。Actions 的自动测试不替代真实桌面验收。

每次构建还上传 `Regression-*` 证据包，包含自动测试结果和基于合成图像的视觉报告。报告检查箭头长度、方向和粗细、文字大小和字重，以及马赛克绘制顺序。另含紧凑工具栏、HSV、中文字稿、窄屏与错位多屏的合成界面截图。CI 使用固定版本 Noto Sans SC 测试字体，附来源、Git blob 校验、SHA-256 与许可证；字体不进入安装包。测试还覆盖 macOS 图像方向转换、缩放裁剪、滑块同步、已有文字样式修改、文字输入和剪贴板失败重试；它们不证明真实屏幕捕获、系统权限或各应用间粘贴已经通过。

具体步骤和记录表见 [实机验收说明](docs/acceptance.md)。
