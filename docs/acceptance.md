# PhotoScreen 实机验收

从草稿 Release 下载 EXE、DMG 和 SHA256SUMS.txt；先核对 SHA-256。记录 Release 版本、系统版本、处理器、屏幕分辨率及缩放比例。两台机器均通过后发布同一草稿，不重新构建。

## 安装与启动

- [ ] Windows：运行安装器，确认安装到当前用户目录；从开始菜单启动，重复启动没有第二个托盘图标。
- [ ] Mac：打开 DMG，将应用拖入“应用程序”；按系统提示打开应用，确认菜单栏图标出现。
- [ ] 设置中切换开机启动，登录系统后验证开关；保持默认关闭。
- [ ] 修改快捷键并重启应用，确认设置保留。使用已被占用的组合时能看到提示，托盘截图入口仍可用。
- [ ] Mac 首次屏幕录制授权被拒绝时能看到说明；在系统设置授权后再次尝试，必要时退出并重启应用。

## 截图与标注

- [ ] 在每块屏幕使用快捷键截图，拖动选区和点击识别窗口均正确；工具栏没有进入复制出的图像。
- [ ] 在屏幕上显示正常方向的文字和上下不同颜色的图案，确认截图预览和粘贴结果方向、颜色均正确；Mac 的文字不能上下颠倒。
- [ ] 有多块屏幕时，分别在每块屏幕测试；使用 Retina 或 125%、150%、200% 缩放时，放大镜、选区和输出像素对齐。
- [ ] **多屏覆盖整台虚拟桌面**：从一块屏拖到另一块屏框选，确认选区能横跨两块屏、覆盖层完整铺满桌面、导出的图片两屏内容都在且比例正确（不被降采样）。
- [ ] **跨屏放大镜**：指针移到另一块屏上时，取色框与十字线显示的是那块屏的像素，不是原屏的。
- [ ] **跨屏尺寸标签**：选区只在单屏内时显示物理像素；选区跨屏时显示逻辑尺寸与跨越的屏数。
- [ ] **混合 DPI 跨屏**：一台 Retina 一台 1x（或 125%/150% 缩放）时，跨屏框选后两屏内容都不错位；Mac 上覆盖层跨不同缩放的屏时整体比例是否一致要单独确认。
- [ ] **多屏逐屏截图的时间差**：屏幕上放一段连续运动的画面，跨屏截图后确认两块屏的内容没有明显错位。
- [ ] 移动、缩放选区；检查矩形、椭圆、箭头、画笔、文字、马赛克和颜色；拖动粗细滑块时确认数值同步变化，且图形随拖动实时更新。分别调整文字字号和字体粗细，确认编辑器与已有文字同步变化；重新选择形状和文字进行移动、缩放及样式修改。
- [ ] 对照 QQ 样例检查不同长度和方向的实心渐粗箭头；调节线宽确认粗细改变，重新选中后调整粗细并拖动两端手柄，粘贴结果与预览一致。
- [ ] 让图形经过选区边缘，在选择工具下拖动选区控制点，确认可以调整选区。小屏幕上确认工具栏可滚动且完成和取消按钮可用。
- [ ] 测试中文输入、文字换行、撤销、重做及删除选中标注；在截图中按 Esc、右键和完成按钮分别验证。
- [ ] 画几个标注后按右键重新框选，确认原有标注和撤销历史都还在，撤销仍能逐个移除。
- [ ] 粘贴到聊天、浏览器和文档应用，检查图像完整且可见；退出 PhotoScreen 后再次粘贴，确认系统剪贴板仍保留图片。
- [ ] 取消截图、拒绝权限或屏幕捕获失败后，原剪贴板内容没有变化；被其他内容覆盖后，应用没有截图历史。

## v1.2 交互实机补充（未验证）

以下各项必须在 Mac 与 Windows 的同一批 v1.2.0 安装包上填写；合成证据与 CI 不勾选这些实机项目。

- [ ] 紧凑工具栏在普通屏、窄屏、上下错位和 L 形屏幕均可见；颜色板、放大镜和尺寸标签没有落入屏幕空隙。
- [ ] 图形只显示颜色/粗细，文字只显示颜色/字号/字重，马赛克不出现无效参数；完整拖到每条滑块两端并检查实时数值。
- [ ] 连续绘制后直接修改新对象，按 V 保持对象选中；矩形/椭圆/画笔/马赛克八方向手柄、文字左右宽度与箭头两端均能使用。
- [ ] 每种工具样式独立，读取旧对象不会污染默认值；关闭、重开应用后恢复主动设置的工具偏好。
- [ ] Shift 约束与方向键 1/10 逻辑单位微调正确；文字输入时 V/R/O/A/P/T/M 为普通输入，滑块方向键只改数值。
- [ ] 使用真实中文输入法验证候选阶段的 Enter/Esc、换行、Ctrl/Command+Enter、Esc 保留草稿、重复编辑和草稿撤销。
- [ ] 长文字保持锚点、不静默丢字；超出选区提示裁切，调整选区后仍能看到保留的全文。
- [ ] 先画箭头/文字，再覆盖马赛克，再添标注：单屏、跨屏混合 DPI 的预览与粘贴结果一致。
- [ ] 取消未完成拖动不增加撤销；无变化提交不增加撤销；复制失败能在当前界面重试，编辑内容不丢失。
